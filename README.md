
# Website Sederhana

## Deskripsi
Website ini dibuat untuk memenuhi tugas praktikum
HTML, CSS, dan JavaScript.

## Fitur Website

- Menggunakan CSS untuk mengatur tampilan.
- Menggunakan background berwarna pastel.
- Memiliki tombol interaktif menggunakan JavaScript.
